# FinGuard AI

## Project Overview

FinGuard is an AI-powered fraud detection platform built using modern DevOps and cloud-native technologies.

## Tech Stack

### Frontend

* React.js
* Vite

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### DevOps

* Docker
* Docker Compose
* Kubernetes
* Helm
* GitHub Actions CI/CD

### Monitoring

* Prometheus
* Grafana

### Cloud

* AWS EC2

## Current Features

* User Authentication
* Transaction Management
* Analytics Dashboard
* Fraud Detection
* Monitoring and Alerting
* Kubernetes Deployment
* CI/CD Automation

## Current Goal

Implement AI-powered fraud risk scoring and fraud explanation engine.

### AI Features Planned

* Risk Score Generation
* Risk Level Classification
* Fraud Explanation Engine
* Transaction Risk Dashboard
